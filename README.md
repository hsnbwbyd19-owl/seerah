# سِيرَة — عِش رحلتك قبل أن تبدأها

«سِيرَة» برنامج سياحي تفاعلي يعتمد على المحاكاة والذكاء الاصطناعي، ويتيح للزائر خوض تجربة سياحية افتراضية قبل زيارة الوجهة على أرض الواقع. يصمّم الزائر رحلة تناسب ميزانيته واهتماماته وعدد أفراد مجموعته، مع إبراز الهوية السعودية والتراث والثقافة المحلية.

> **الرؤية:** أن نجعل اكتشاف السعودية تجربة تبدأ افتراضيًا، وتتحول إلى رحلة واقعية مليئة بالمعرفة والمتعة والانتماء.

## طريقة التشغيل

المتطلبات: Node.js بالإصدار 20 أو أحدث.

```bash
npm install
npm run dev
```

ثم افتح المتصفح على: http://localhost:3000

لتشغيل نسخة الإنتاج (أسرع وأنسب للعرض أمام لجنة التحكيم):

```bash
npm run build
npm start
```

> الخطوط تُنزَّل من Google Fonts مرة واحدة أثناء `npm run build` وتُخزَّن داخل المشروع، فلا يحتاج الموقع إلى الإنترنت بعد البناء.

## ربط المرشد الذكي بـ Claude (اختياري)

1. أنشئ ملفًا باسم `.env.local` في جذر المشروع (يمكنك نسخ `.env.example`).
2. ضع مفتاحك بداخله:

   ```
   ANTHROPIC_API_KEY=sk-ant-...
   ```

3. أعد تشغيل الخادم (`npm run dev`).

ستظهر في نافذة المحادثة شارة «ذكاء اصطناعي» عندما يكون الرد قادمًا من Claude.

**بدون مفتاح؟ لا مشكلة.** إذا كان المفتاح غير موجود، أو تعذّر الاتصال بالإنترنت، أو تأخر الرد، فسيتحول المرشد تلقائيًا إلى ردود جاهزة ذكية مبنية على بيانات كل وجهة: الأكلات، والتاريخ، واللبس، والعادات، والميزانية. وتظهر حينها شارة «وضع العرض». لن يتعطل العرض في أي حال.

## الصفحات

| الصفحة | المسار | الوصف |
| --- | --- | --- |
| الرئيسية | `/` | الهيرو والرؤية، وكيف تعمل سيرة، وأنواع التجارب، والأثر المتوقع، ونظام النقاط |
| مخطط الرحلة | `/planner` | خمس خطوات مع شريط تقدم: الوجهة، ونوع الرحلة، والتفاصيل، والباقة مع جدول التكلفة، والملخص |
| المحاكاة | `/simulation` | خط زمني لكل يوم (صباح، ظهر، مساء)، وخريطة SVG للمسار، وزر «زيارة» يضيف النقاط، ومرشد يعلّق على كل محطة |
| المرشد الذكي | `/guide` | محادثة مع «راوي» بلهجة بيضاء، مع أسئلة جاهزة |
| المحفظة | `/wallet` | الرصيد بالنقاط وبالريال، وسجل النقاط، ومتجر المكافآت، وشارات الإنجاز |

## العرض التجريبي

يفتح الموقع على رحلة نموذجية جاهزة: **الأحساء، رحلة عائلية، 4 أفراد، يومان، باقة الدِّيرة**، مع 180 نقطة مسجلة مسبقًا. سيناريو مقترح للعرض:

1. من الصفحة الرئيسية اضغط «شاهد الرحلة النموذجية».
2. في المحاكاة اضغط «زيارة» على جبل القارة: تظهر حركة احتفالية ويتجاوز الرصيد حد الاستبدال (200 نقطة).
3. اسأل المرشد: «وش أشهر أكلة هنا؟».
4. افتح المحفظة واستبدل «قهوة سعودية وتمر».
5. لإعادة الحالة الأصلية بعد العرض: زر «إعادة ضبط العرض التجريبي» في صفحة المحفظة.

تُحفظ الرحلة والنقاط في `localStorage` داخل المتصفح.

## نظام النقاط

- النقطة الواحدة = هللة واحدة (كل 50 نقطة = 50 هللة، وكل 100 نقطة = ريال واحد).
- الحد الأدنى للاستبدال: 200 نقطة.
- سبع شارات إنجاز، منها: مستكشف الأسواق، وحارس التراث، ورحّال المملكة.

## البيانات

كل البيانات تجريبية (Mock) في ملفات JSON داخل مجلد `data/`، ولا توجد قاعدة بيانات:

- `destinations.json`: خمس وجهات (الأحساء، العُلا، الدرعية، أبها، جدة التاريخية) بمعالم حقيقية، وأكلات محلية، ونطاقات أسعار فندقية.
- `packages.json`: ثلاث باقات: الرحّال (اقتصادية)، والدِّيرة (متوسطة)، والصقر (فاخرة).
- `rewards.json` و`badges.json`: المكافآت والشارات.

**تنبيه:** جميع الأسعار استرشادية وتقديرية لأغراض العرض فقط، وتختلف حسب الموسم ومقدّم الخدمة.

## التقنيات

- Next.js (App Router) + TypeScript
- Tailwind CSS 4
- Framer Motion للحركات
- Anthropic SDK (`@anthropic-ai/sdk`) في مسار `app/api/guide/route.ts`
- الخطوط: Reem Kufi للعناوين، وAref Ruqaa للشعار، وIBM Plex Sans Arabic للنصوص
- يدعم الوضع الليلي، ومتجاوب بالكامل مع الجوال

## بنية المشروع

data/           بيانات JSON
lib/            التسعير، وبناء المسار، والحالة، وردود المرشد الاحتياطية
